About Chat Room

A disposable, no-registration group chat. Click Create a room to get a random 8-character code, share it (or the room link) with anyone, and they join instantly from any device, anywhere. No accounts, no phone numbers, no history left behind.

Messages are relayed in memory and never written to disk. File attachments are stored only temporarily on the server so everyone in the room can download them, and they are deleted along with the whole room the instant the last person leaves. Executable and script files (.exe, .dll, .bat, …) are blocked; other common types — zip, tar, 7z, images, PDFs, video — are allowed up to 2 GB each.

Great for a quick huddle, sharing files across your own devices, or a throwaway room you never have to clean up. Keep the tab open to stay in the room.
