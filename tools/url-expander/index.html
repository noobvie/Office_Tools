About the URL Expander

Paste a short or suspicious link (bit.ly, t.co, tinyurl, a link from an email…) and this tool follows it one hop at a time: HTTP redirects (301, 302, 303, 307, 308), the Refresh header and <meta http-equiv="refresh">. It shows each hop's status, host and server address, then the final destination as plain text with a Copy button — never as a clickable link, so you can decide before you visit. Tracking parameters such as utm_source or fbclid are detected and a clean copy is offered.

Our server, not your browser, visits every hop. That keeps your address hidden from the link's owner, but it also means: do not paste one-time links — password resets, magic login links, unsubscribe or confirmation links. Expanding one can use it up. JavaScript is never run: common script redirects on the final page are reported as a warning but not followed. Some link services send bots and real browsers to different places, so a browser may still end up somewhere else. Links that point at private or internal addresses are refused and never fetched.
