File Drop

Send files and text between any two devices — like AirDrop, but it works across Windows, macOS, Linux, Android and iPhone. Peer-to-peer and end-to-end encrypted: files travel directly between your devices and are never uploaded to a server.

About File Drop

File Drop is a cross-platform AirDrop alternative that runs entirely in the browser — nothing to install on either device. Open this page on both devices: if they share the same Wi-Fi or network they discover each other automatically; for a device somewhere else, pair with a 6-digit code.

Transfers use WebRTC peer-to-peer connections: the file streams directly from one device to the other, end-to-end encrypted (DTLS). Our server only brokers the initial handshake — a few KB of connection metadata — and never sees, stores or relays your files. On the same network, data never even leaves your LAN, so large files move at local network speed.

Send documents from a MacBook to a Windows PC, photos from your phone to your laptop, or paste a link to another device with the text-message option. File size is limited only by the receiving device's disk space in modern Chromium browsers; both tabs must stay open during a transfer.
